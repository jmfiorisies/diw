    8.1 · Manipulación del DOM, Eventos e Interacción

    Criterios trabajados

    Criterio Cobertura
    RA4.e — Agregar elementos multimedia a documentos Web ✅ Completa

    1. El DOM como árbol de objetos

    El documento HTML desarrollado en la UD3 se transforma, tras su carga en el navegador, en una estructura jerárquica de objetos directamente manipulables mediante JavaScript: el Document Object Model (DOM).

    flowchart TD
    DOC["document"] --> HTML["html"]
    HTML --> HEAD["head"]
    HTML --> BODY["body"]
    BODY --> MAIN["main"]
    MAIN --> ART["article.card-producto"]
    ART --> H3["h3.card-producto__title"]
    ART --> BTN["button.btn--primary"]
    Concepto Definición técnica
    Nodo (Node) Punto genérico del árbol: abarca elementos, atributos, fragmentos de texto y comentarios.
    Elemento (Element) Tipo concreto de nodo que representa directamente una etiqueta HTML.
    Árbol DOM Representación jerárquica y estructurada en memoria de todos los nodos de la página.

    2. Selección de elementos en el DOM

    Método de selección Retorno Ámbito de aplicación
    document.getElementById('id') Elemento único o null Selección directa por identificador único. Alta velocidad de consulta.
    document.querySelector('.clase') Primer elemento coincidente Consultas mediante selectores CSS. Devuelve una única coincidencia.
    document.querySelectorAll('.clase') NodeList estático con coincidencias Selección de múltiples elementos para su posterior iteración. 
    const boton = document.querySelector('.btn--primary');
const tarjetas = document.querySelectorAll('.card-producto');

tarjetas.forEach(tarjeta => {
  console.log(tarjeta.dataset.productoId);
});

    3. Manipulación dinámica del DOM (RA4.e)

    3.1 Modificación de contenido y atributos

    const titulo = document.querySelector('.card-producto__title');
titulo.textContent = 'Nuevo nombre de producto'; // Inserción segura de texto (Previene XSS)
titulo.innerHTML = '<strong>Producto</strong> destacado'; // Modificación de nodos HTML estructurados

const imagen = document.querySelector('.card-producto__image');
imagen.setAttribute('src', 'nueva-imagen.webp');
imagen.alt = 'Descripción actualizada del producto';

    Seguridad en la inserción de contenido (XSS)

    El uso de innerHTML con entradas provenientes del usuario (como comentarios, formularios o búsquedas) expone la aplicación a vulnerabilidades de tipo Cross-Site Scripting (XSS). Para la renderización de texto plano es obligatorio utilizar textContent.

    3.2 Creación e inserción de elementos multimedia

    function agregarImagenGaleria(srcWebp, srcFallback, descripcion) {
  const picture = document.createElement('picture');

  const source = document.createElement('source');
  source.srcset = srcWebp;
  source.type = 'image/webp';

  const img = document.createElement('img');
  img.src = srcFallback;
  img.alt = descripcion;
  img.loading = 'lazy';

  picture.append(source, img);
  document.querySelector('.galeria').appendChild(picture);
}

    Conexión con la optimización multimedia (UD6)

    Al agregar contenido multimedia mediante JavaScript es imprescindible aplicar los mismos principios de optimización definidos en la UD6: selección de formatos modernos (WebP/AVIF), alternativas de fallback, texto alternativo accesible (alt) y carga diferida (loading="lazy").

    4. Eventos y manejo de interacción (RA4.f)

    4.1 Ciclo de procesamiento de eventos

    flowchart TD
    A["Usuario realiza una acción<br/>(clic, teclado, interacción)"] --> B["El navegador emite un objeto Event"]
    B --> C["El Event Listener escucha el tipo de evento"]
    C --> D["Se ejecuta la función manejadora (Callback)"]

    const boton = document.querySelector('.btn--añadir-carrito');

boton.addEventListener('click', (event) => {
  event.preventDefault();
  console.log('Producto añadido al carrito correctamente');
});
    Evento Momento de activación
    click Activado al pulsar con el puntero o mediante la tecla Enter/Espacio en elementos enfocables.
    input Se dispara de forma inmediata cada vez que el valor de un campo <input> o <textarea> cambia.
    submit Se emite al enviar un formulario (vía botón o confirmación por teclado).
    keydown / keyup Ocurre al presionar o soltar una tecla del teclado.
    mouseenter / mouseleave Activado cuando el cursor entra o sale de la superficie de un elemento.
    load Se activa cuando un recurso asociado (imagen, script o página) ha finalizado su carga.

    4.2 Delegación de eventos

    Al trabajar con múltiples elementos interactivos equivalentes (como listados de tarjetas o botones de tabla), resulta más eficiente asignar un único escuchador en el elemento contenedor padre que añadir escuchadores individuales en cada nodo hijo:

    // Enfoque ineficiente: Registra N escuchadores independientes en memoria
document.querySelectorAll('.btn--eliminar').forEach(btn => {
  btn.addEventListener('click', eliminarTarjeta);
});

// Enfoque optimizado mediante Delegación: Único escuchador en el contenedor
document.querySelector('.lista-productos').addEventListener('click', (event) => {
  if (event.target.matches('.btn--eliminar')) {
    eliminarTarjeta(event);
  }
});

    flowchart TD
    subgraph Directo ["Asignación Individual"]
        A["100 botones con listeners independientes"] --> P1["Mayor consumo de memoria,<br/>impacto al crear/eliminar elementos"]
    end

    subgraph Delegacion ["Delegación de Eventos"]
        B["1 listener en el contenedor padre"] --> P2["Patrón eficiente:<br/>gestiona elementos creados<br/>dinámicamente en el DOM"]
    end

    4.3 Validación interactiva de formularios con JavaScript

    Complementando la validación nativa de HTML5 vista en la UD3, JavaScript permite implementar reglas de negocio complejas y gestión de errores en tiempo real:

    const form = document.querySelector('.form-registro');
const password = document.querySelector('#password');
const confirmacion = document.querySelector('#confirmacion');
const mensajeError = document.querySelector('#password-error');

form.addEventListener('submit', (event) => {
  if (password.value !== confirmacion.value) {
    event.preventDefault();

    // Gestión dinámica de errores en el DOM
    mensajeError.textContent = 'Las contraseñas no coinciden';
    mensajeError.hidden = false;

    // Comunicación de estado accesible (Conexión con RA5)
    confirmacion.setAttribute('aria-invalid', 'true');
    confirmacion.setAttribute('aria-describedby', 'password-error');
    confirmacion.focus();
  }
});

    Conexión con la Accesibilidad Web (RA5)

    Los atributos aria-invalid y aria-describedby permiten comunicar dinámicamente los errores detectados a tecnologías asistivas (como lectores de pantalla). La validación visual creada para usuarios de ratón se vuelve accesible para todos los usuarios mediante el uso de atributos ARIA.

    5. Ejercicio práctico guiado

    Actividad de consolidación (no evaluable)

    Objetivo: Desarrollar comportamiento dinámico interactivo sobre los componentes diseñados en las unidades UD3-UD7.

    **Pasos recomendados para practicar:**

1. **Galería interactiva:** Crea un selector de imágenes donde al pulsar sobre una miniatura se actualice la vista principal utilizando manipulación del DOM (**RA4.e**).
2. **Validación dinámica:** Implementa la validación mediante JavaScript de un formulario de opinión/reseña visualizando mensajes de error contextuales.
3. **Delegación de eventos:** Gestiona las interacciones de un catálogo de productos (por ejemplo, botones "Añadir a favoritos") utilizando un único listener en el elemento padre (**RA4.f**).
4. **Soporte Accesible:** Añade atributos ARIA (`aria-invalid`, `aria-describedby`) en los flujos de validación del formulario.
