## 🟢 Detalle del RA7 Dualizado (100% en Empresa)

El **Resultado de Aprendizaje 7** se transfiere íntegramente a la estancia en empresa para aplicarse sobre un entorno real de producción frontend:

* **RA7.a / RA7.b:** Comunicación asíncrona, evaluación de rendimiento y consumo de APIs REST/GraphQL.
* **RA7.c / RA7.d:** Métodos HTTP, gestión de peticiones, almacenamiento y estado de servidor con **TanStack Query**.
* **RA7.e / RA7.f:** Renderizado dinámico, intercambio de datos (`JSON`, `FormData`) y arquitectura de estado global (**Zustand / Context API**).
* **RA7.g:** Pruebas e integración entre navegadores y entornos (**Vitest, React Testing Library y Playwright**).
* **RA7.h / RA7.i:** Uso de librerías en producción, pipelines de **CI/CD** y seguridad web (**CSP, prevención de XSS y manejo seguro de Cookies**).
